# Боевой кейс: WB-отзывы → LLM → CSV

Полный прогон: [agent-hub-code-mode](https://github.com/nekto9852-bit/agent-hub-code-mode).
Здесь — только то, что породило улучшения ядра.

## Задача

100 реальных отзывов Wildberries → классификация LLM (категория + тональность) → CSV → сводка. Управление — через конвейер агента (интервью → бриф → «да» → исполнение → аудит → память), n8n — через Code Mode.

## 5 итераций ремонта → 5 улучшений ядра

| # | Сбой (первопричина из логов) | Что починили в ядре |
|---|---|---|
| 1 | Легаси OpenAI-креды n8n мертвы (401/404) | — (переход на HTTP-ноду к другому провайдеру) |
| 2 | Нода без Authorization → 401 | — (заголовок добавлен) |
| 3 | LLM пересобирает JS при `updateWorkflow` и ломает экранирование: `"` → `"""`, SyntaxError на компиляции ноды | **`setNodeCode`** — код едет файлом, сервер читает и пишет сам |
| 4 | n8n запрещал запись файла наружу | `N8N_RESTRICT_FILE_ACCESS_TO` в сервисе n8n |
| 5 | HTTP-нода затирала поля отзыва ответом LLM (классифицировались пустые строки) | item linking по индексу с нодой-источником |

Плюс два пост-мортемных улучшения:

- **`verifyNodeCode`** — на итерации 4 агент отчитался «код корректен», показав свой замысел вместо факта. Серверная сверка хэшей закрывает класс «ложный успех».
- **Секрет-страж + `exportWorkflowSafe`** — при подготовке публичного репо в export-JSON нашлись зашитый ключ API и email владельца проекта. Теперь execute не даёт писать сырые секреты, экспорт санитайзится на сервере, workflow носит `={{$env.NAME}}`-ссылки.

## Итог прогона

- 100/100 отзывов с текстом, классификация: похвала 76 / вопрос 24 / жалоба 0
- 8.1с пайплайн против ~2ч вручную (экспертная оценка)
- После миграции на `$env`-ссылку: `rawSecretsFound: []`, `safeToPublish: true`

## Уроки (нетехнические)

1. Лимит итераций ремонта без протокола эскалации → агент начинает «пробовать ещё» и галлюцинировать успех. Решение в SOUL.md: на 3-й итерации — стоп и handoff оператору.
2. Правдивость аудита — свойство системы, не дисциплины модели: каждое «готово» должно опираться на серверную проверку (файл перечитан, хэш сверен).
3. Секреты протекают не там, где их ждешь: не в логах, а в артефактах (export workflow). Санитайзер обязателен на выходе, не только страж на входе.
